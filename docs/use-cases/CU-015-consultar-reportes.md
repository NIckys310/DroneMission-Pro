# CU-015 — Consultar reportes

| | |
|---|---|
| **Actor** | Administrador, Operador, Cliente |
| **Precondición** | Permiso REPORTES_VER. |
| **Requerimientos** | RF-027 |
| **Postcondición** | Reporte descargado. |

## Flujo principal

1. Abre Reportes.
2. Elige el reporte.
3. Descarga el PDF.
4. Queda en el historial.

## Flujos alternativos

- Cliente: solo misiones propias y finalizadas.
