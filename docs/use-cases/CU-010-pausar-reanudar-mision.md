# CU-010 — Pausar / reanudar misión

| | |
|---|---|
| **Actor** | Piloto |
| **Precondición** | Misión EN_VUELO. |
| **Requerimientos** | RF-018 |
| **Postcondición** | Misión EN_VUELO de nuevo. |

## Flujo principal

1. Pulsa Pausar e indica el motivo.
2. El drone virtual se detiene.
3. Pulsa Reanudar.

## Flujos alternativos

- 1a. Un incidente CRÍTICO pausa la misión automáticamente.
