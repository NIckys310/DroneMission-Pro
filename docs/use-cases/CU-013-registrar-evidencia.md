# CU-013 — Registrar evidencia

| | |
|---|---|
| **Actor** | Piloto, Operador |
| **Precondición** | Misión en preparación, vuelo, pausada o finalizada. |
| **Requerimientos** | RF-025 |
| **Postcondición** | Evidencia disponible. |

## Flujo principal

1. Pulsa Evidencia.
2. Elige tipo.
3. Sube un archivo o indica una URL.
4. Indica si es visible para el cliente.
5. Guarda.

## Flujos alternativos

- 3a. Archivo no permitido o > 20 MB: error.
