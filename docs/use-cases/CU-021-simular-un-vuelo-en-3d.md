# CU-021 — Simular un vuelo en 3D

| | |
|---|---|
| **Actor** | Todos (Piloto principalmente) |
| **Precondición** | Sesión iniciada. |
| **Requerimientos** | RF-034, RF-035 |
| **Postcondición** | El usuario practicó la misión sin riesgo. |

## Flujo principal

1. Abre 'Simulador 3D' (o 'Ver en simulador 3D' desde una misión).
2. Elige práctica o misión real y las condiciones.
3. Pulsa 'Cargar en el simulador'.
4. Pulsa 'Despegar' y observa con cámara de seguimiento, cenital o libre.
5. Ajusta la velocidad (1×–10×) y revisa el registro del vuelo.

## Flujos alternativos

- Inyecta 'Batería crítica', 'Ráfaga de viento' o 'Pérdida de señal' para practicar emergencias.
- Pulsa 'Regresar a base' (tecla H) o 'Pausar' (barra espaciadora).
