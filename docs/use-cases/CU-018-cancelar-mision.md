# CU-018 — Cancelar misión

| | |
|---|---|
| **Actor** | Operador |
| **Precondición** | Misión antes del vuelo. |
| **Requerimientos** | RF-020 |
| **Postcondición** | Misión CANCELADA. |

## Flujo principal

1. Pulsa Cancelar misión.
2. Escribe el motivo.
3. El sistema cambia a CANCELADA y notifica.

## Flujos alternativos

- Misión en vuelo: no se puede cancelar (debe finalizarse).
